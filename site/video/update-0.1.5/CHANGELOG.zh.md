# Ely Office 0.1.5 更新日志

## 全部应用
- 二级菜单更好选：鼠标斜着移向子菜单时，路过的项不再抢先弹出；子菜单右侧放不下时改在左侧打开。
- 应用已开着时再打开文件，直接在原窗口开成新标签，不再提示“已在运行”。
- 中文显示统一：Windows 上同一个词不再一半粗一半细；界面里残留的英文改为中文。
- macOS 安装包已签名并经 Apple 公证，打开时不再提示“无法验证开发者”。

## ElyMark
- 表格可以在格内直接编辑：点哪格开哪格，Tab 与方向键在格间移动，回车或 Esc 写回。
- 右键菜单随所点的内容变化：剪贴板、复制为 Markdown / HTML / 纯文本、格式、段落、表格、图片。
- “段落”“格式”菜单与快捷键和 Typora 一致（如 Ctrl+1–6 设标题）。
- 支持 `:表情:`、GitHub 提示块、`[toc]` 目录、front matter 与常用行内 HTML。
- 侧栏可清除最近文件，重启后仍保持清空。

## ElyDoc
- 右键菜单照 Word：正文、表格、图片各有对应的菜单。
- 拖动表格边线即可调整列宽与行高。
- 光标在表格里时，属性栏把表格设置排在最前。

## ElyTable
- 右键菜单照 Excel：单元格、行列表头、图形各有对应的菜单。

## ElyShow
- 右键菜单照 PowerPoint；表格边线可以拖动。
- 左侧幻灯片缩略图条可以用滚轮滚动（修复 Linux Wayland 上的问题）。
