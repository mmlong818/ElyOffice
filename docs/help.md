# 帮助

## 打开与保存

- 文件菜单在每个应用里相同：新建、打开、保存（Cmd+S）、另存为、导出（Cmd+E）、打印（Cmd+P）；Cmd+W 关闭标签，Cmd+, 打开设置。
- 新建的文档在第一次保存时才选位置。保存保留原格式；另存为写新文件，原文件不动。
- 含宏的文件、已签名的 PDF、修复过的 PDF 只能另存副本，上方提示条写明原因。
- 外部程序改了你正在编辑的文件时，Ely 不覆盖，询问从磁盘重载、保留你的版本或另存副本（ElyMark 另可逐处比较合并）。
- 自动保存：ElyMark 对有路径的文件停手 1 秒后保存。ElyDoc、ElyTable、ElyShow、ElyPDF 默认手动保存，可在设置“文档”里打开“自动保存”：只对本应用自有格式、无宏无签名的文件，外部改动或保存失败后停下等你处理。

## 缩放与窗口宽度

- ElyDoc、ElyTable、ElyShow：Cmd+= 放大，Cmd+- 缩小，Cmd+0 回到实际大小（ElyShow 为适合幻灯片）；也可在“视图”菜单、状态栏右侧的缩放控件，或按住 Cmd 滚动、触控板捏合（以指针处为中心）。范围 25% 至 400%。
- 窗口变窄时，两侧栏先变窄，再先收起右栏、后收起左栏，文档区至少保留 360 点；窗口变宽即回来。侧栏的宽度可拖动内侧边缘调整，按应用记住。
- 侧栏放不下全部文字时，分页按钮只显示图标，悬停可见名称。

## ElyMark 的菜单与快捷键

- 段落与格式菜单照 Typora。菜单里带 Shift 的标点键写成所出的字符，如 Ctrl+{ 即 Ctrl+Shift+[。标题：Ctrl+1 至 Ctrl+6，Ctrl+0 段落，Ctrl+= 与 Ctrl+- 升降一级。块：Ctrl+Shift+K 代码块，Ctrl+Shift+M 公式块，Ctrl+Shift+Q 引用，Ctrl+Shift+[ 有序列表，Ctrl+Shift+] 无序列表，Ctrl+Shift+X 任务列表。
- 格式：Ctrl+B 加粗，Ctrl+I 斜体，Ctrl+U 下划线，Ctrl+Shift+` 代码，Alt+Shift+5 删除线，Ctrl+K 超链接，Ctrl+Shift+I 插入图片，Ctrl+\ 清除样式。
- 表格在“段落 ▸ 表格”：Ctrl+T 插入，Ctrl+Enter 下方插入行，Ctrl+Shift+Backspace 删除行，Alt+方向键移动行列，“格式化表格源码”对齐各列。
- 视图：Ctrl+/ 在源代码与可视之间切换，F8 专注，F9 打字机，Ctrl+Shift+= 放大，Ctrl+Shift+- 缩小，Ctrl+Shift+0 实际大小（Windows 的中文输入法占着这个键，在 Windows 上用 Ctrl+Shift+9）；可视、源码、预览在“视图”菜单里选。
- 编辑：Ctrl+Shift+C 复制为 Markdown（无选区时复制全文），Ctrl+Shift+V 粘贴为纯文本；另有复制为纯文本、复制为 HTML 代码（图片保留原地址）、复制为富文本。
- 右键菜单照 Typora，随所点之处变化：剪切、复制、粘贴、删除为一行图标；链接可打开、复制地址；图片可打开所在位置（网络图片在浏览器打开）、删除；代码块可复制其内容；公式与 HTML 块可编辑；加粗、斜体、代码、超链接与引用、列表各为一行图标；表格里为“表格 ▸”，别处为“段落 ▸”；“插入 ▸”；引用、列表、代码块等可整块删除。右键落在选区里时选区保留；正在编辑的块右键后仍开着。源码模式只有剪贴板与“复制／粘贴为”，预览只有复制。
- 命令用不了时（如在代码里设标题、插入点不在表格里），提示写明原因，文字不动。macOS 上 Ctrl 为 Cmd。

## 恢复

- 有未保存改动时，每 10 秒在本机数据目录写一个恢复点（加密的文档其恢复点也加密），只留在本机，不上传。
- 应用崩溃后再启动，未保存的内容以未命名副本打开，原文件不动；只恢复内容，光标与撤销历史不恢复。
- 文档引擎单独停止时，窗口上方写明原因与最近一次恢复点的时间，“重新打开文档”起新引擎并逐个重开：有改动的从恢复点、无改动的从文件。
- 设置“存储”里可看日志、恢复副本的大小，选每个文档保留几个恢复点与多少空间，并清除它们（先问）。

## 离线边界

- 六个应用都不需要网络、账号或在线服务；启动与空闲时不连网。
- ElyMark 不连网：文档里的网络图片不加载，HTML 不运行。本机图片照文档里写的路径读：相对路径从文档所在文件夹算起，`..`、绝对路径与 `file:` 地址可指向别处。
- ElyTree 只在你取回、拉取、推送、克隆时连网，凭据照用你的 Git 设置（credential helper、ssh-agent），Ely 不在终端问密码。
- 检查更新只在你手动检查时进行，下载后校验，从不静默安装。

## 仓库操作（ElyTree）

- 改动页：暂存、取消暂存、按块或按行暂存，放弃改动与清理未跟踪文件每次都先问并列出会删的文件。
- 历史页：搜索提交、文件历史、逐行追溯；分支页：切换、合并、变基（先问）、标签。
- 强制推送写明会覆盖的提交，只推所示的那个提交，远端在你上次取回后变了即被拒。
- 引用日志可找回删掉的分支；“把当前分支移到此”保留工作区改动，从不做硬重置。
- 另一个 Git 正在工作时（锁文件），Ely 说明原因并可重试，从不删除锁文件。
